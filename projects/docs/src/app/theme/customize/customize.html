Customize Theme

A theme is a set of CSS custom properties applied to the document through data-ngs-theme and data-ngs-color-scheme. Component styles read the --ngs-* tokens, while Tailwind utilities read the mapped --color-* aliases.

Import themes

Import one of the prebuilt themes or your own theme file from the global stylesheet. The default theme is enough for a single-theme app; import additional themes when users can switch between them.

Create a custom theme

Create a stylesheet such as src/styles/themes/acme.scss. Define the light tokens under [data-ngs-theme='acme'] and the dark tokens under the same theme with data-ngs-color-scheme='dark' or the .dark class.

Use the theme by default

Register the theme name in provideNgsTheme. The service writes data-ngs-theme, data-ngs-color-scheme, data-ngs-density, and data-ngs-radius to the document root.

Switch themes at runtime

Inject ThemeManagerService anywhere you need a theme control. The selected theme is persisted by default, unless persistence is disabled in provideNgsTheme.
