The NgStarter Angular Suggestions component lets you render a grouped visual list of contextual suggestions, search results, recent items, or shortcuts. Use ngs-suggestions as the visual list inside search dropdowns, assistant inputs, command-like panels, or contextual suggestion popovers. It includes examples for Basic suggestions.

Basic suggestions

Use suggestions to show grouped search results, recent items, users, files, pages, or quick create actions inside a dropdown-style surface. Use form controls such as autocomplete or select when the user is choosing a form value.
