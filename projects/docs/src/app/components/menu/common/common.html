Menu

The Menu component provides a customizable and versatile dropdown or context menu system. It supports multi-level nesting, icons, dividers, and various positioning strategies, making it ideal for navigation and action menus in modern web applications.

Key Features:
  • ✅ Nesting: Supports unlimited levels of nested submenus.
  • ✅ Flexible Positioning: Automatic positioning relative to the trigger element.
  • ✅ Custom Content: Use with icons, dividers, and custom headers/footers.
  • ✅ Lazy Rendering: Content is only rendered when the menu is opened.
