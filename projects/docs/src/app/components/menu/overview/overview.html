The NgStarter Angular Menu component lets you show a short contextual set of commands in an overlay opened from a trigger or right-click area. Use ngs-menu for row actions, overflow more actions, user menus, context menus, toolbar actions, and nested command groups. It includes examples for Basic Menu, Menu With Icons, Menu Divider, and Menu Heading.

Keyboard access

A mouse click opens the menu without moving focus to a command. Tab or Shift+Tab focuses the trigger without opening the menu. Enter, Space, or Down opens a menu and focuses the first available command; Up opens it at the last command. Up and Down navigate commands, Home and End jump to the first and last command, and typing letters finds a command by its label. Enter or Space activates the command. Escape returns to the trigger. Tab closes the menus and continues the page's focus sequence.

Right opens a submenu and Left returns to its parent; these directions reverse in RTL layouts. A focusable context-menu trigger also supports Shift+F10 and the Context Menu key.
