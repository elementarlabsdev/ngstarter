Header, subheader, and footer

ngs-layout-header and ngs-layout-subheader accept boolean flex and autoHeight inputs. ngs-layout-footer accepts block and autoHeight. These inputs default to false. Heights default to 3.5rem and can be overridden through height utility classes or --ngs-layout-header-height, --ngs-layout-subheader-height, and --ngs-layout-footer-height. Set autoHeight to size the region to its content.
