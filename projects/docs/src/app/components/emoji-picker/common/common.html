Emoji Picker

The Emoji Picker component provides a user-friendly interface for selecting emojis from various categories. It supports multiple languages and can be easily integrated into any input field or message editor.

Key Features:
  • ✅ Wide range of emojis: Supports a vast library of emojis categorized for easy navigation.
  • ✅ Multi-language support: Automatically adapts to the user's locale or a specified language.
  • ✅ Flexible positioning: Can be used with a trigger and positioned relative to it.
  • ✅ Responsive and lightweight: Optimized for performance and works across all device sizes.
