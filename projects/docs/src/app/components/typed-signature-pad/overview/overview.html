The NgStarter Angular Typed Signature Pad component lets users type initials, names, or short signature text, choose a font and color, and emit the rendered signature as an SVG data URL. Use ngs-typed-signature-pad in PDF signing, approval, onboarding, consent, checkout, and document workflows where typed signatures are accepted.

When to use

Use TypedSignaturePad when a workflow needs a keyboard-entered signature that can be saved with selected font and color metadata. It is designed to pair with document builders, PDF signing dialogs, approval flows, and forms where typed signatures or initials are accepted.

Output

The component emits both the rendered SVG data URL and the source metadata, so application code can store the image while still preserving the typed text, selected font family, and color.
