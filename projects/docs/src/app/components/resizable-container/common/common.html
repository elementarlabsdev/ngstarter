Resizable Container

The Resizable Container component is a versatile UI element that allows users to adjust the width of a content area dynamically. It provides a draggable handle for resizing, making it ideal for creating flexible layouts, sidebars, or preview panels.

Key Features:
  • ✅ Interactive Resizing: Smooth, real-time width adjustment via a draggable handle.
  • ✅ Configurable Constraints: Define minimum width to maintain layout integrity.
  • ✅ Event Notification: Emits events on resize for synchronized UI updates.
  • ✅ Flexible Content: Can wrap any content, including charts, text, or complex components.
