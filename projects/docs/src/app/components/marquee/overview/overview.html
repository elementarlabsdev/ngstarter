The NgStarter Angular Marquee component lets you display an infinite horizontal stream of repeated non-critical content. Use ngs-marquee for motion content that can move and repeat without losing meaning: promo text, short highlights, logos, badges, partner names, compact news, and decorative content showcases. It includes examples for Basic marquee, Marquee reverse, Marquee with pause on hover, and Marquee pause on hover.

Basic marquee

Use a basic marquee for non-critical content that can move and repeat without losing meaning.

Marquee reverse

Use reverse when the visual direction should match surrounding layout or create alternating motion.

Marquee with pause on hover

Use pause on hover when the moving content contains text or interactive items that need extra time.
