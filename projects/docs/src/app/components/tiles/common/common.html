Tiles

The Tiles component provides a flexible and responsive grid-based layout for displaying content in card-like containers. It supports drag-and-drop reordering, customizable column spanning, and responsive dimensions, making it ideal for dashboards, galleries, and interactive interfaces.

Key Features:
  • ✅ Drag-and-Drop: Interactive reordering of tiles with smooth animations.
  • ✅ Responsive Design: Configure tile width and height for different breakpoints (sm, md, lg, xl).
  • ✅ Flexible Layout: Customizable grid columns and gap spacing.
  • ✅ Developer-Friendly: Simple API for tracking order changes and layout updates.
