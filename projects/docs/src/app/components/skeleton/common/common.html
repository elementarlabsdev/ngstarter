Skeleton

The Skeleton component is used to provide a visual indication that content is loading. It creates a placeholder that mimics the layout of the actual content, helping to reduce perceived loading time and improve user experience.

Key Features:
  • ✅ Visual Feedback: Provides immediate feedback that content is on its way.
  • ✅ Layout Stability: Maintains the layout of the page while content is loading.
  • ✅ Customizable: Can be styled to match any content type.
