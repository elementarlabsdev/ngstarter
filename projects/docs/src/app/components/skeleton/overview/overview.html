The NgStarter Angular Skeleton components preserve layout while content is loading. Import Skeleton, SkeletonCircle, and SkeletonRectangle from @ngstarter-ui/components/skeleton for text lines, avatars, cards, and media blocks.

Basic Skeleton

Use Skeleton blocks to approximate the loaded layout with TailwindCSS size and layout utilities. Use ngs-skeleton-circle with a size-* class for avatars and icons, and ngs-skeleton-rectangle with h-* and w-* classes for cards and media. All variants share the same loading animation and theme colors. Rectangular corners follow the theme radius: 1rem in default and 0.25rem in chalk. Circle placeholders remain fully round in both themes.
