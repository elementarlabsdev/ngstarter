Usage

Import the standalone pieces you use from the secondary entry point.

Use compact label and description inputs for simple status lists.

Bind activeIndex to resolve auto items dynamically from application state. Explicit states such as error and disabled stay fixed. Use an activeIndex equal to the item count when every auto-state step is finished.

Project label and description elements when the item content needs a richer template.

Register completed and error indicator icon templates at the tracker level.

Configure default indicator icon names globally with the Step Tracker environment provider.
