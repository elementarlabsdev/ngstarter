Drawer

The Drawer component is a panel that slides out from the edge of the screen. It is commonly used for navigation, filters, or additional context without losing the current page state.

Key Features:
  • ✅ Flexible Positioning: Slides out from the right side of the screen.
  • ✅ Backdrop Support: Optional backdrop to focus user attention on the drawer content.
  • ✅ Overlay Integration: Built on top of Angular CDK Overlay for robust behavior.
  • ✅ Animations: Smooth transition animations for opening and closing.
