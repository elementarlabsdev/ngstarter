Comment Editor is an Angular-native composer for comments, messages, replies, and activity feeds. It keeps its original product behavior—compact and expanded states, projected toolbar, bubble menu, footer actions, links, lists, media uploads, YouTube embeds, cancel/send flows—and now runs on the signal-based @ngstarter-ui/components/editor foundation. JSON is the source of truth; send can also emit serialized HTML.

Basic Comment Editor

The complete example shows projected controls, text and block formatting, links, image upload, YouTube embeds, programmatic insertion, JSON submission, and HTML output.
