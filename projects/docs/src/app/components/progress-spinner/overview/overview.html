The NgStarter Angular Spinner component lets you show a circular indicator for an ongoing operation. Use ngs-progress-spinner when a compact circular loading indicator is needed inside a button, overlay, media viewer, widget, small page area, or next to an action. It includes examples for Basic Progress Spinner, Configurable Progress Spinner, and Configurable spinner.

Basic Progress Spinner

Use the basic spinner for compact loading states inside buttons, overlays, media viewers, widgets, or small page areas.

Configurable Progress Spinner

Configure mode, value, color, diameter, and stroke width when the spinner needs to match the operation scope or show known progress.
