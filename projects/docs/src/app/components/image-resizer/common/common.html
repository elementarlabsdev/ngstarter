Image Resizer

The Image Resizer component provides an intuitive interface for resizing images within your application. It supports constraints like minimum and maximum width and emits events when dimensions change.

Key Features:
  • ✅ Flexible Resizing: Easily adjust image dimensions with interactive handles.
  • ✅ Constraints: Set minimum and maximum width to maintain layout integrity.
  • ✅ Event Emission: Get real-time updates on image dimensions and natural size.
  • ✅ Easy Integration: Works with standard HTML image elements via directives.
