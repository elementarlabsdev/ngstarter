The NgStarter Angular Image Resizer component lets you let users interactively change the displayed width of an img element with side drag handles. Use ngs-image-resizer around a standard img marked with ngsImageResizerImage when users need to manually choose how large an image appears in an editor, content form, thumbnail preview, banner preview, or media preparation flow. It includes examples for Basic image resizer.

Basic image resizer

Drag the handles to change the displayed width of the image. Use the emitted dimensions to store the chosen display size in your editor or form state.
