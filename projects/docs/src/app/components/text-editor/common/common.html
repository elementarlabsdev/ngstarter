Text Editor

The Text Editor component is a powerful, flexible, and feature-rich WYSIWYG editor based on Tiptap. It provides a seamless experience for creating and editing rich text content, with support for various formatting options, image uploads, and custom extensions.

Key Features:
  • ✅ Rich Formatting: Support for bold, italic, strike, code blocks, lists, and more.
  • ✅ Tiptap Integration: Built on top of the Tiptap editor for maximum extensibility.
  • ✅ Customizable Toolbar: Optional toolbar with configurable visibility.
  • ✅ Image Uploads: Built-in support for image uploads with custom upload functions.
