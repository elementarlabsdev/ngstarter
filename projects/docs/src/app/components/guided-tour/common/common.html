Guided Tour

Guided Tour component is a powerful tool for creating interactive walkthroughs and onboarding experiences in your Angular applications. It helps users understand complex features and workflows by highlighting specific elements and providing step-by-step instructions.

Key Features:
  • ✅ Interactive Steps: Guide users through various parts of your application.
  • ✅ Anchor-based Highlighting: Easily attach tour steps to specific UI elements.
  • ✅ Customizable Templates: Fully control the appearance and content of each step.
  • ✅ Backdrop Support: Focus user attention by dimming the rest of the screen.
  • ✅ Flexible Navigation: Support for keyboard, backdrop click, and programmatic control.
