The NgStarter Angular Notifications component lets you display user-facing notification events in a structured feed or inbox. Use Notifications for events addressed to the current user: comments, mentions, invitations, assignments, access requests, status changes, completed processes, and user-specific updates. It includes examples for Basic notifications, Notification variants, and Notification list.

Basic notifications

Use a basic notification when composing one user-facing event directly in a template.

Notification variants

Use notification variants to show richer user-specific events with avatars, icons, nested context, chips, and inline actions.

Notification list

Use a notification list when notifications come from data and each notification type needs a template.
