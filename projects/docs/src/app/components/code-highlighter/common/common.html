Code Highlighter

The ngs-code-highlighter component provides a powerful way to display source code with syntax highlighting using the Shiki library. It supports multiple themes, line highlighting, diff view, and more.

Key Features:
  • ✅ Modern Highlighting: Powered by Shiki for accurate and beautiful syntax highlighting.
  • ✅ Customizable Themes: Support for various Shiki themes like github-light, nord, etc.
  • ✅ Line Highlighting: Easily highlight specific lines or ranges of code.
  • ✅ Diff Support: Built-in support for displaying code changes with diff highlighting.
  • ✅ Copy to Clipboard: Optional button to allow users to quickly copy code.
