Confirm

The Confirm component is a specialized dialog designed to prompt users for a clear decision, such as confirming an action or acknowledging a message. It provides a consistent and user-friendly way to handle critical interactions within your application.

Key Features:
  • ✅ Clear Intent: Designed specifically for binary choices (Yes/No, Confirm/Cancel).
  • ✅ Easy Integration: Simple API to trigger confirmation dialogs from anywhere in your app.
  • ✅ Configurable Content: Easily set the title and description to match the context of the action.
  • ✅ Consistent UX: Ensures that all confirmation prompts follow the same design language.

Perfect for delete operations, form submissions, or any action that requires an extra layer of verification to prevent accidental mistakes.
