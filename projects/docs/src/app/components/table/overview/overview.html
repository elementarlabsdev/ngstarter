The NgStarter Angular Table component lets you render static or template-defined tabular data with known columns. It supports Angular cell templates, local sorting, filtering, pagination, selection, sticky rows, and fixed columns.

Native Table

Use the native table styling wrapper for static HTML tables that do not need an Angular data source.

Basic Table

Use ngs-table when a simple dataset has known columns and custom cell templates.

Table With Pagination

Connect TableDataSource to Paginator for local pagination on small or moderate static datasets.

Table With Sorting

Use ngsSort with ngs-sort-header when column headers should emit active column and direction for local or server-side sorting.

Table With Filtering

Use TableDataSource filtering for simple local text filtering. Use DataView or FilterBuilder for richer dataset filtering.

Table With Selection

Add Checkbox and SelectionModel when rows in a simple table can be selected.

Table With Fixed Columns

Use sticky columns for simple wide tables that need important columns or actions to remain visible.

Table With Fixed Header

Use a sticky header when a simple table scrolls inside a bounded container.

Table With Fixed Footer

Use a sticky footer for totals or summary rows in a simple table.

Drag and drop rows table

Use drag and drop sorting when users reorder rows manually. This is different from column header sorting.
