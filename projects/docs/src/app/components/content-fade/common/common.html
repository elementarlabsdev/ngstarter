Content Fade

The Content Fade component is a sleek and effective way to indicate that content continues beyond the visible area. It applies a smooth gradient overlay to the edges of a container, providing a visual cue to users that there is more to see.

Key Features:
  • ✅ Visual Continuity: Clearly indicates hidden content without abrupt cut-offs.
  • ✅ Flexible Positioning: Apply fade to the start, end, or both sides of the container.
  • ✅ Customizable Appearance: Easily adjust the color and width of the fade effect to match your design.
  • ✅ Lightweight & Efficient: Built for performance with minimal overhead.
