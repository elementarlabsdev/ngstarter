Bottom Sheet

The BottomSheet is a service for opening Material Design bottom sheets. A bottom sheet is a surface anchored to the bottom edge of the screen that presents supplementary content while retaining the current context.

Key Features:
  • ✅ Flexible Content: Open components or templates as bottom sheets.
  • ✅ Configurable: Customize backdrop, closing behavior, focus, and dimensions.
  • ✅ Service-based: Easy to trigger from anywhere in your application.
  • ✅ Lifecycle Management: Provides references to track the state of opened bottom sheets.
