Crop

Fast, modern, and easy image cropping for Angular — fully compatible with and TailwindCSS.

Add a polished, production-ready image cropping experience to your Angular app with minimal setup. The component is touch-friendly, responsive, and integrates seamlessly with dialogs, forms, and theming.

  • ✂️ Interactive cropping
    Drag to crop, pinch to zoom, and adjust with mouse or touch.
  • 🧩 integration
    Works with MatDialog, reactive forms, themes and accessibility patterns.
  • 📱 Responsive & mobile-first
    Adapts to any screen size and input method.
Perfect for:

👤 Avatar uploaders, 📰 content editors, 📦 admin dashboards, 🧠 AI tools — any app that needs a simple and powerful image cropping experience.

🚀 Image Crop Component — the modern open-source solution for effortless image cropping in Angular.
