Dialog Service

Сервис Dialog используется для открытия модальных окон.

Methods

Name Description
open(componentOrTemplateRef, config?) Открывает диалоговое окно с указанным компонентом или шаблоном.
closeAll() Закрывает все открытые диалоговые окна.

Dialog Configuration

Объект DialogConfig используется для настройки поведения и внешнего вида диалога.

Property Type Description
data any Данные, передаваемые в компонент диалога.
width string Ширина диалога.
height string Высота диалога.
disableClose boolean Запрещает закрытие диалога при клике на фон или нажатии Escape.

Directives & Components

DialogTitle

Заголовок диалога. Автоматически генерирует уникальный ID для ARIA.

Input Type Description
id string Уникальный идентификатор заголовка.

DialogActions

Контейнер для кнопок действий в нижней части диалога.

Input Type Description
align 'start' | 'center' | 'end' Выравнивание кнопок действий. По умолчанию 'end'.

DialogClose

Директива для кнопок, закрывающих диалог.

Input Type Description
ngsDialogClose any Результат, с которым будет закрыт диалог.
