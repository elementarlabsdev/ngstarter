All APIs on this page are exported from @ngstarter-ui/components/editor. The editor service must be scoped with provideNgsEditor(); it is intentionally not a root singleton.

Browser behavior

  • Native selection is translated to stable block IDs and text offsets.
  • beforeinput handles typing, replacement, paragraph splits, deletion, formatting, undo, and redo.
  • Plugins receive paste first; the default fallback inserts plain text and turns newlines into paragraphs.
  • IME composition keeps browser DOM control until compositionend, then commits one JSON transition.
  • Rendering is initialized with afterNextRender(), keeping server rendering free from direct DOM setup.
  • The core provides behavior and state only. Placeholder visuals, focus rings, spacing, toolbar layout, and all other styling belong to the host.
