Composition model

  1. provideNgsEditor() creates an editor instance scoped to the host.
  2. withEditorPlugin() installs the required blocks, marks, commands, and services.
  3. ngsEditorSurface synchronizes the JSON model with contenteditable and native selection.
  4. ngsEditorCommand binds typed commands to toolbar controls without losing selection.
  5. The host reads signals or calls commands directly; the core does not own layout or visual styling.
