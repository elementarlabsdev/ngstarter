Color Picker

The Color Picker component allows users to select colors through a graphical interface. It supports various formats like HEX, RGB, and HSL, and provides features like opacity control and a preview of the selected color.

Key Features:
  • ✅ Multi-format Support: Work with HEX, RGB, and HSL color formats.
  • ✅ Opacity Control: Fine-tune color transparency with an easy-to-use slider.
  • ✅ Visual Preview: Instantly see the selected color in a dedicated thumbnail.
  • ✅ Flexible Integration: Use it as a standalone component or as a popover triggered by other elements.
