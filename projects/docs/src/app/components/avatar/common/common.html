Avatar

The Avatar component is used to represent a user or entity with an image, initials, or icon. It supports different variants, sizes, and can be grouped together.

Key Features:
  • ✅ Flexible Content: Display images, text labels, or icons.
  • ✅ Visual Variants: Support for solid, tonal, outlined, and plain styles.
  • ✅ Automatic Colors: Dynamically generate background and text colors.
  • ✅ Avatar Groups: Easily stack multiple avatars together.
