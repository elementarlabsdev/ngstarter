Image Zoom viewer

The Image Zoom viewer component provides an interactive way to view images with a smooth zoom-in effect. It is perfect for galleries, product pages, or any scenario where users need to see image details clearly.

Key Features:
  • ✅ Smooth Animation: Uses CSS transitions for a fluid zoom experience.
  • ✅ Overlay Support: Displays the zoomed image in a centered overlay.
  • ✅ Responsive: Automatically recalculates zoom level on window resize.
  • ✅ Accessibility: Supports closing via the Escape key and backdrop clicks.
