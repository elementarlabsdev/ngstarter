Timeline

The Timeline component is used to display a series of events in chronological order. It is ideal for showing activity logs, project milestones, or any history-based information.

Key Features:
  • ✅ Chronological Layout: Clearly presents events in a vertical flow.
  • ✅ Customizable Content: Each timeline item can include titles, descriptions, timestamps, and custom attributes.
  • ✅ Flexible Indicators: Use default dots or custom icons/components as event markers.
  • ✅ Sub-components: Highly modular structure with headers, items, titles, and more for full control.
