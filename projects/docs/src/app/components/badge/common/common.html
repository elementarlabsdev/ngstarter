Badge

The Badge component is a small, informative element typically used to display counts, status, or labels. It can be easily attached to other components to provide additional context without taking up much space.

Key Features:
  • ✅ Contextual Information: Great for showing notifications, counts, or status updates.
  • ✅ Flexible Positioning: Supports multiple positions relative to the host element.
  • ✅ Customizable Appearance: Choose from different sizes and colors to match your design.
  • ✅ Dynamic Visibility: Easily hide or disable the badge based on your application's state.

Whether you need to show the number of unread messages or highlight a new feature, the Badge component is a versatile tool for your UI.
