Grid

Grid is a configuration-driven 12-column renderer for dashboard and widget layouts. It receives configs that map widget types to lazy-loaded components, and items that define each widget id, type, column span, height, content, skeleton, and nested children.

Use it for admin dashboards, configurable widget layouts, analytics home screens, portal start pages, and nested dashboard sections where widget components are rendered from configuration or data. Do not use it as a normal CSS layout helper for forms, pages, cards, or repeated elements; use Tailwind grid/flex classes for that.
