Video Viewer

The Video Viewer component is designed for seamless video playback within your application. It provides a rich set of features including customizable overlays, titles, and descriptions, ensuring an engaging user experience across all devices.

Key Features:
  • ✅ Overlay Integration: Opens video in a full-screen or modal-like overlay for focused viewing.
  • ✅ Rich Content Support: Easily add titles, captions, and descriptions to your videos.
  • ✅ Responsive Playback: Optimized for various orientations (landscape, portrait, square).
  • ✅ Advanced Controls: Full control over autoplay, muting, and visibility of playback controls.

Perfect for galleries, educational platforms, or any application that requires a professional-grade video viewing experience.
