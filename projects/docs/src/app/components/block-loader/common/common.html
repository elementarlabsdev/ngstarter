Block Loader

The Block Loader component is used to indicate a loading state for specific sections or elements within an application. It provides a visual cue to users that content is being fetched or processed, ensuring a smooth and informative user experience.

Key Features:
  • ✅ Section Loading: Easily overlay any container to show it's currently busy.
  • ✅ Customizable Spinner: Adjust diameter and stroke width to match your UI.
  • ✅ Container Integration: Works seamlessly with the ngsBlockLoaderContainer directive.
