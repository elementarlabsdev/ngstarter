Currency Select

The Currency Select component is a powerful and flexible tool designed for web applications that require internationalization and financial data entry. It provides an intuitive interface for users to search and select currencies from a comprehensive list.

Key Features:
  • ✅ Comprehensive Currency List: Includes global currencies with their codes and names.
  • ✅ Search Functionality: Users can quickly find currencies by name or code.
  • ✅ Customizable Display: Option to show country names alongside currencies.
  • ✅ Integration-Ready: Works seamlessly with Angular Forms and FormField components.
