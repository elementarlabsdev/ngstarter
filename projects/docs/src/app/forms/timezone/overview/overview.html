The NgStarter Angular Timezone Select component lets you let users choose an IANA time zone id in a form field. Use ngs-timezone-select inside one ngs-form-field when a form must store a real time zone id such as Europe/Warsaw or America/New_York. It includes examples for Basic timezone select.

Basic timezone select

Use timezone select when the saved value should be a real time zone id. It provides a searchable, grouped list of supported time zones and works with Angular forms.
