Inline Text Edit

The Inline Text Edit component allows users to edit text directly in place, providing a smooth and efficient user experience. It's perfect for titles, descriptions, and other editable content where a full form might be overkill.

Key Features:
  • ✅ In-place Editing: Seamless transition between viewing and editing modes.
  • ✅ Customizable Placeholder: Clearly indicate when content is missing.
  • ✅ Debounced Updates: Control the frequency of change emissions with a configurable delay.
  • ✅ Keyboard Support: Use Enter to save and Escape to cancel edits.
