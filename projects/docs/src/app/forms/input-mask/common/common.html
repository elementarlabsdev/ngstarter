Input Mask

The Input Mask component is a powerful tool for enforcing specific formatting on user inputs. It ensures that data is entered in a consistent and valid format, such as credit card numbers, expiry dates, or CVV codes.

Key Features:
  • ✅ Formatted Input: Automatically formats user input as they type.
  • ✅ Validation Support: Works seamlessly with Angular forms for validation.
  • ✅ Specialized Masks: Pre-configured masks for common credit card fields.
