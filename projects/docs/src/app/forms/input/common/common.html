Input

The input component is a wrapper around the native HTML input and textarea elements. It provides a consistent look and feel across different browsers and devices, while also adding support for features like floating labels, error messages, and hints.

Key Features:
  • ✅ Standard HTML Integration: Works seamlessly with native input and textarea.
  • ✅ Floating Labels: Supports dynamic labels that respond to user interaction.
  • ✅ Form Field Support: Integrates perfectly with form fields for hints and errors.
  • ✅ Customizable: Easy to style and extend to fit any design system.
