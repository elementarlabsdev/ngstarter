Button Toggle

The Button Toggle component allows users to select one or more options from a set of related buttons. It provides a clear and intuitive way to switch between different states or modes in your application.

Key Features:
  • ✅ Single or Multiple Selection: Configure the toggle group to allow only one or several selections.
  • ✅ Customizable Appearance: Choose between different styles to match your application's design.
  • ✅ Responsive and Accessible: Optimized for various devices and screen sizes, ensuring a seamless user experience.
  • ✅ Easy Integration: Simple to implement and use within Angular projects.
