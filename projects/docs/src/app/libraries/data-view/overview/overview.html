Data View

The NgStarter Angular Data View component lets you build operational data grids for records that users need to inspect, organize, select, and act on. Use for datatables and working data surfaces in admin screens, CRM and ERP records, users, orders, invoices, logs, tasks, assets, and any dataset where the table is the main interactive work surface. It includes examples for Data View, Basic data view, Data view with selection, and Data view with pagination.

Data View is an operational data grid for records that users need to inspect, organize, select, and act on. Build it with columnDefs and either local data or a server-side datasource. It supports sorting, search/filter state, pagination, row selection, loading states, empty states, column resizing, column visibility, column order, pinned or sticky columns, custom cell renderers, refresh, and an optional action bar.

Use Data View for admin screens, CRM and ERP records, users, orders, invoices, logs, tasks, assets, and any dataset where the table is the main work surface. Use the simpler Table component for small static tables or read-only tabular content that does not need row selection, column operations, pagination, server loading, or custom cell behavior.
