Visual Builder

VisualBuilder is currently an experimental scaffold for a future no-code or low-code visual workspace. The current ngs-visual-builder component does not provide production builder behavior yet: it has no inputs, outputs, layout regions, canvas, drag and drop, inspector, persistence, or editable block model.

Do not use VisualBuilder for production admin screens or real builders yet. Use ContentEditor for block-based CMS content, ImageDesigner for creative image composition, Tiles for editable dashboard widgets, Grid for static dashboard layouts, FormRenderer for backend-driven forms, and KanbanBoard for workflow columns.
