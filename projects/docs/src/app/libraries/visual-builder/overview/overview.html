Visual Builder

The NgStarter Angular Visual Builder component lets you experimental scaffold for a future no-code or low-code visual workspace. Do not use ngs-visual-builder for production admin screens, dashboards, visual editors, page builders, or real no-code/low-code workflows yet. It includes examples for Visual Builder.

VisualBuilder is currently an experimental scaffold for a future no-code or low-code visual workspace. The current ngs-visual-builder component does not provide production builder behavior yet: it has no inputs, outputs, layout regions, canvas, drag and drop, inspector, persistence, or editable block model.

Do not use VisualBuilder for production admin screens or real builders yet. Use ContentEditor for block-based CMS content, ImageDesigner for creative image composition, Tiles for editable dashboard widgets, Grid for static dashboard layouts, Form Builder for schema-driven forms, and KanbanBoard for workflow columns.
