Mentions

Add teammate mentions with a menu anchored to the text caret. Configure an Angular option component once in the plugin, or supply a custom menu template for an individual surface. The editor keeps focus while the menu is open, so typing continues to filter suggestions.

Register the plugin

Import from @ngstarter-ui/components/headless-editor and install mentionEditorPlugin() through withHeadlessEditorPlugin(). This provides its options in the editor's injector scope. All mention surfaces in that scope share the configured component and search callback; separate editors can use different configurations.

Custom option component

Candidates require an id and label and may include any presentation data. The component receives option and active inputs. Place avatars, descriptions, or other content inside it. The surrounding MenuItem handles selection and highlighting.

Per-surface menu template

Pass a Menu to ngsHeadlessEditorMentions to override the default menu. Import Menu and MenuItem from @ngstarter-ui/components/menu. Render suggestions(), give each item its optionId(index), highlight activeIndex(), and call select(option) when an item is clicked.

Async search callback

Set options to a callback with the signature (query: string) => Promise<readonly User[]>. It receives the search text without the trigger, including an empty string when the user types only @. Filter a local array as shown above, or return results from your backend. Returned candidates keep their order and are not filtered again by the plugin.

The directive clears previous suggestions while searching and ignores outdated responses. Rejected searches leave the menu closed and expose the error through error(); loading() reports a pending search. A new query starts another search. To use a different callback on one surface, bind [mentionOptions]="searchUsers". Ignoring an outdated response does not cancel its network request.

Search and keyboard behavior

  • Type @ at the start of text or after whitespace or an opening bracket. E-mail addresses do not open the menu.
  • Arrow keys choose a suggestion; Enter or Tab inserts it; Escape dismisses the current query.
  • The directive also handles mentions inside table cells when their marks allow mentions.
  • No menu opens during composition, for read-only editors, or when no candidates match.

Document value and undo

Selecting a candidate replaces the trigger and query with its label and a trailing space in one undo step. Formatting around the query is preserved, and the space has no mention mark. The selected candidate is emitted through mentionSelected.

Mentions are editable text marks. They are not atomic tokens: users can edit their text and delete individual characters. Style .ngs-headless-editor-mention through the surface class with ::ng-deep or global styles, and map the mark explicitly in your HTML serializer.
