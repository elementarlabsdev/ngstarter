Editor

Editor is the unstyled Angular foundation behind rich text experiences in NgStarter. It combines signal state, a versioned JSON document, DOM selection synchronization, snapshot history, and a small plugin contract without prescribing a finished editor UI.

Use it to:
  • Build a custom editor surface and toolbar from Angular components.
  • Add blocks, marks, commands, keyboard shortcuts, paste behavior, and services through plugins.
  • Share one document engine between Comment Editor and future Content Builder integrations.
  • Store and transport editor content as JSON rather than DOM or HTML state.

Use Comment Editor when you need a ready-made comment composer. Use Editor when the host application owns the layout, controls, styling, and feature set.
