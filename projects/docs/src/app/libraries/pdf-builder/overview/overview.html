PDF Builder

The NgStarter Angular PDF Builder component provides a contract document builder workspace with a block palette, layers, editable PDF canvas, selected-block toolbar, and inspector panel for document automation interfaces.

Use PDF Builder for document automation products that need a builder surface rather than a finished PDF viewer: users can compose contract sections, place variables, inspect selected blocks, validate clauses, and prepare a document for review or export.

The component is exposed from @ngstarter-ui/components/pdf-builder and renders as <ngs-pdf-builder />. The basic example page shows the full builder workspace.
