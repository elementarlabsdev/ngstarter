Motion JSON Schema

Motion documents describe a composition as data: canvas settings, assets, scenes, layers, timing, animations, transitions, audio, and export options. The studio edits this shape visually, while the player renders the same JSON without studio-only state.

composition assets scenes layers animations transitions audio export
Document

The document root keeps render settings and references to reusable objects. Layer ids stay stable so timelines, scenes, selection state, and JSON import/export can point to the same entities.

 Layer

A layer owns visual content, layout, style, timing, keyframes, and optional enter/exit transitions. Text, shape, image, video, group, and audio layers share the same timeline contract. 

{{ layerExample }}
 Scene

Scenes are named time ranges that group the visible layer ids for a section of the video. They make longer videos editable as chapters and allow scene-level transitions. 

{{ sceneExample }}
 Audio

Audio is stored as a layer so trimming, fades, mute, solo, and scene export use the same scheduling model as visual elements. 

{{ audioExample }}
 Export Job

Export settings can be saved alongside the document or passed to the render runner. The same JSON can target previews, scene renders, transparent clips, GIFs, and final MP4 output.
