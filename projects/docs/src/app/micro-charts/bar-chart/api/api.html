API Reference for Bar Chart

import { MchartBar } from '@ngstarter-ui/components/micro-chart';

Input Description
data: number[] Array of numeric values to be displayed in the chart.
labels: string[] Array of strings to be used as labels for the data points.
gap: number The gap between bars (default: 0.2).
radius: number The corner radius of the bars (default: 0).
highlight: boolean Whether to highlight bars on hover (default: false).
responsive: boolean Whether the chart should resize automatically to fit its container (default: false).
fillGradient: boolean Whether to use a gradient fill for the bars (default: false).
xAccessor: (d: any, i: number) => any Function to access the x-value (index by default).
yAccessor: (d: any) => any Function to access the y-value (value by default).
tooltip: TemplateRef<any> Optional template for the tooltip.
tooltipPosition: OverlayPosition Position of the tooltip (default: 'after-center').
